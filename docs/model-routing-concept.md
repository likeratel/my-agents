# 모델 역할 분담 컨셉

> 상태: 아이디어 보관용. 아직 설정·라우팅·구독을 변경하지 않는다.

## 목표

대화와 전체 조율은 Codex의 Astra를 중심으로 하고, 설계·구현·리뷰를 모델별 강점에 따라 나눈다.

## 구상한 역할

| 단계 | 모델 |
| --- | --- |
| 사용자와의 소통·전체 조율 | Codex Astra |
| 설계 | Astra + Claude Fable |
| 코딩 | Claude Opus + Codex Sol |
| 리뷰 | Astra + Fable |

## 나중에 검토할 기본 흐름

`Astra가 조율 → Sol이 일반 구현 → Opus가 어려운 구현 → Astra가 1차 리뷰 → Fable이 설계·최종 리뷰`

모든 작업에 고성능 모델을 동시에 호출하지 않고, 일반 작업은 Sol을 기본으로 하며 복잡한 설계·구현·최종 검토에만 Astra, Fable, Opus를 추가하는 방향을 우선 검토한다.

## 구독 한도 메모

Claude와 Codex 모두 모델·문맥·도구 사용량에 따라 실제 소모량이 달라진다. Claude 앱과 Claude Code, ChatGPT와 Codex는 각각 사용량을 공유할 수 있으므로, 이 역할 분담을 실제로 적용하기 전에는 각 서비스의 주간 한도와 사용량 화면을 기준으로 다시 판단한다.
