다이어그램 패턴

복사해서 좌표와 글자만 바꿔 쓰는 모음. 전부 인라인 SVG·CSS이고 외부 의존이 없습니다.

1. 가로 흐름

단계가 순서대로 이어질 때. 단계마다 부연이 필요하면 두 줄로 씁니다.

2. 계층 · 위임

하나가 여럿을 거느릴 때. 조직도, 오케스트레이션, 모듈 구성.

3. 반복 루프

같은 절차를 되풀이할 때. 재시도와 순회처럼 루프가 겹치면 되돌아오는 선의 깊이를 달리해 아래로 뺍니다 — 본 흐름을 가리지 않습니다.

4. 시퀀스

주고받는 순서와 방향이 중요할 때. 반환은 점선으로 구분합니다.

5. 대비 (HTML/CSS)

두 선택지를 나란히 놓을 때. 이런 모양은 SVG보다 HTML이 고치기 쉽습니다.

내리는 게 나을 때

  • 파일을 여러 개 열어야 하는데 결론만 필요할 때
  • 서로 의존하지 않는 작업이 여럿일 때
  • 같은 코드를 다른 눈으로 볼 때

직접 하는 게 나을 때

  • 파일 하나 읽으면 끝나는 일
  • 이미 컨텍스트에 있는 내용
  • 무엇을 원하는지 아직 안 정해진 일

6. 단순 흐름 (HTML/CSS)

칸이 서너 개고 좌표를 잡을 이유가 없을 때. 좁은 화면에서 세로로 접힙니다.
