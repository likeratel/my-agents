# 문서 작성

프로젝트의 기존 문서 형식과 사용자의 요청을 따른다. HTML 문서와 이해 확인 퀴즈는 필수가 아니다.
문서는 필요한 경우에만 만들고, 관련 README·CHANGELOG 등 정본을 우선 갱신한다.

독립 HTML 산출물을 선택한 경우 `~/.agents/my-agents/templates/document.html`과
`diagram-patterns.html`을 활용할 수 있다. 외부 네트워크 없이 열리도록 스타일·이미지를 포함하고,
라이트·다크와 좁은 화면에서 읽을 수 있는지 확인한다. SVG의 텍스트는 텍스트로 유지하고 제목을 제공한다.
