# 보안

시크릿을 코드·로그·문서에 하드코딩하거나 노출하지 않는다. 환경 변수나 시크릿 관리 도구를 사용한다.
시스템 경계에서 입력을 검증하고, SQL은 매개변수화하며 HTML·에러 응답에 민감 정보가 새지 않게 한다.
인증·인가·개인정보 등 변경에 관련된 보안 위험을 검증한다. 변경과 무관한 전체 감사는 기본 요구가 아니다.
독립 감사가 필요하고 허용되면 auditor를 사용한다. 불가능하면 한계와 직접 검증 결과를 알린다.
노출된 시크릿을 발견하면 추가 노출을 막고 사용자에게 알린다. 회전·폐기는 기존 승인 범위와 운영 영향을 확인한다.
